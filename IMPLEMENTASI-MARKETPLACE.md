# Implementasi fitur marketplace Indonesia

Checkpoint 17 Oktober 2026: seller Shopee dan Tokopedia & Shop, creator serta affiliate partner Indonesia. Semua tenant memakai role dinamis dan isolasi data. Tidak ada perubahan toko nyata; kunci marketplace lokal kosong dan akses Creator API/beta/TAP belum dimiliki.

Pusat **Fitur Commerce** (`/commerce`) menyediakan **308 operasi Shopee dan 272 operasi Tokopedia & Shop executable lokal**. Shopee mencakup 307 kontrak default dan satu unduhan OBS privat; Tokopedia & Shop mencakup 270 kontrak default dan dua alur persiapan video besar. Matriks [748 operasi](IMPLEMENTASI-COMMERCE-OPERASI.csv) menjelaskan fitur aktif, izin, principal, scope/program, transport, sumber dan alasan penundaan; [rekap mesin](backend/docs/audits/commerce-coverage.json) memakai registry/kebijakan server yang sama. Angka ini tidak memasukkan alur khusus sebagai fitur pusat dan tidak menyatakan akses sandbox atau seluruh fitur platform selesai.

| Area | Yang sudah tersedia dan diuji lokal | Batas yang masih terbuka |
|---|---|---|

| Affiliate | AMS seller dan creator Video/LIVE Shopee serta operasi affiliate seller/creator/partner Tokopedia & Shop sesuai principal, termasuk kolaborasi/campaign/sample/showcase/link/laporan | Shopee publisher/affiliate terpisah belum memiliki kontrak terverifikasi; negara akun user Shopee belum dapat diverifikasi provider dan ditandai di UI; entitlement program nyata belum diuji |

Input/hasil cache berlaku 24 jam, file satu jam. Cleanup berkala berjalan melalui worker, termasuk tenant yang sedang ditutup. Riwayat tetap mempunyai batas akses domain meskipun koneksi diputus; hasil cache disaring ulang mengikuti izin saat dibaca. Perubahan yang hasilnya tidak diketahui tidak dikirim ulang otomatis. Status diterima API berbeda dari selesai diproses marketplace.

Kontrak bersumber dari 428 endpoint/28 modul snapshot Shopee yang dipin serta 317 operasi default/390 versi API resmi Tokopedia & Shop. Semua method Shopee eksplisit pada sumber Markdown; extractor lama yang melaporkan 143 tidak diketahui sudah diperbaiki. Metadata statis tidak dihitung sebagai bukti alur khusus pada audit referensi literal.

Reproduksi matriks: dari `backend/`, jalankan `pnpm build` lalu `node tools/audit-commerce.mjs`. Compiler kontrak dan hash sumber dijelaskan di README connector. Tidak ada kode pihak ketiga dari snapshot yang dijalankan.

Validasi lokal: 1.005 tes unit/paket backend dan 582 tes UI pada suite penuh lulus; 11 tes UI terfokus kemudian memeriksa tampilan hasil instalasi parsial. Compiler kontrak mencakup 12 tes Shopee dan 12 tes TikTok serta enam tes extractor bukti HTTP. OpenAPI 243 path dan kedua SDK diperbarui. Sebanyak 132 kasus integrasi terkait memakai database/role aplikasi dan Redis nyata lulus. Seluruh 13 tes browser produksi pada lebar 320/390/768/1440 piksel lulus, termasuk aksesibilitas dan multipart native. Proses api/webhook/worker/scheduler nyata lulus 23 pemeriksaan HTTP lokal tanpa panggilan marketplace. Validasi PRD tetap 259 FR dan 294 kriteria; katalog baru tidak otomatis menutup seluruh PRD. Hasil lokal tidak menggantikan pengujian akun sandbox yang telah memperoleh scope/program.
